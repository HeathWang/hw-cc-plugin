# Grill Me

## Overview

Interview the user relentlessly about every aspect of the plan until shared understanding is reached. Walk down each branch of the design tree, resolving dependencies between decisions one by one.

## When to Use

- User wants to stress-test, pressure-test, challenge, red-team, or poke holes in a plan
- User says "grill me", "grill me on my design", "interrogate this design", or "challenge my plan"
- User says "拷问", "帮我拷问一下", "方案评审", or asks for a hard review of a technical方案

## Process

Ask one question at a time, then wait for the user's answer before continuing.

For each question, include your recommended answer or default position so the user has something concrete to react to.

If a question can be answered by exploring the codebase, explore the codebase instead of asking.

Stop when the major decision branches are resolved, then summarize the agreed direction, remaining risks, and unresolved questions.

## Common Mistakes

- Do not ask a batch of questions at once.
- Do not answer for the user and move on.
- Do not skip codebase exploration when the repository can answer the question.
